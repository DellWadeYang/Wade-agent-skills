# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for this repository.

ADRs capture significant architectural decisions, the context, and the consequences of those decisions. They provide a historical record of why certain architectural choices were made.

## Format

ADRs should follow the standard ADR format:
- A unique numeric prefix (e.g., `0001-`, `0002-`)
- A descriptive title
- Sections for context, decision, and consequences

## Usage

The engineering skills in this repository will read ADRs from this directory when exploring the codebase to understand architectural decisions that may affect the work being done.

See `docs/agents/domain.md` for more information on how domain documentation is consumed by the skills.
